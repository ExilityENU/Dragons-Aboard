# Changelog

## 1.0.0 — 2026-11-15

Initial release.

- Hover hold: dragons flying/hovering within reach above a deck stay with the ship (turns and climbs included)
- Calm decks: sitting/stay-ordered tamed mobs stop fighting the moving deck
- Fall-damage protection aboard ships
- Server config: hover range, toggles, extra entity namespaces/ids
- `#dragonsaboard:affected` entity tag for datapacks
